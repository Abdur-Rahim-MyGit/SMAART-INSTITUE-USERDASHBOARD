# Documentation — user dashboard

Everything written about this repository lives here. The polished, presentation-ready
documents are one level up in **[My Project Document](../My%20Project%20Document/)** —
start there if you want the current, complete picture. This folder is the working history
behind it.

| Folder | Contains |
|---|---|
| `01-System` | How the system works: the end-to-end flow, the user journey, the operations manual, the toolkit, notifications, registration fields, vision boards, career intelligence. |
| `02-Deployment` | Earlier and alternative deployment guides. **The current procedure is [`DEPLOY.md`](../DEPLOY.md) and [`Hosting.docx`](../My%20Project%20Document/Hosting.docx).** |
| `03-Audits-and-Security` | Pre-launch audits, the security review and its remediation record, and per-area bug reports. |
| `04-Testing` | Test strategy and the manual testing guide. |
| `05-Planning-and-Roadmap` | Improvement plans, the task roadmap, open decisions and session handovers. |
| `06-Reference-PDFs` | Generated reference PDFs and source requirement documents. |
| `07-Technical-Docs-and-Reports` | The deep technical references — assessment system, course structure, skills audit — plus the generated report set. |
| `08-Business-and-Product` | Master flow document, pricing plan and product-side material. |
| `09-Requirements-and-Source-Material` | Original requirement documents, master data workbooks, flow diagrams and screenshots. |

Superseded scratch files and one-off scripts are kept in [`../Archive`](../Archive/) rather
than in the repository root.
