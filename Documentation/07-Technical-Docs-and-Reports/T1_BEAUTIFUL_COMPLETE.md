### 🎯 Scoring System (LOCKED)

**5-Band System**:
```
🏆 Advanced    (81-100%) - Purple gradients
💪 Strong      (61-80%)  - Emerald/Teal gradients
📈 Progressing (41-60%)  - Final Minds Teal (#30919D)
🌱 Developing  (21-40%)  - Amber/Orange gradients
🌟 Emerging    (0-20%)   - Rose/Red gradients
```

**Calculation**:
```javascript
// For each quotient
quotient_percentage = (correct_answers / total_questions) × 100
quotient_band = determineBand(quotient_percentage)

// Overall baseline
baseline_score = average(all_quotient_percentages)
stage_band = determineBand(baseline_score)
```
