# SMAART Minds - Design System

## Color Palette

### Primary Colors
- **Deep Blue**: `#004D99` (HSL: 210 95% 30%) - Main brand color for primary actions and headers
- **Teal**: `#42A89B` (HSL: 170 50% 45%) - Secondary color for accents and supporting elements

### Accent Colors
- **Warm Gold**: `#B58539` (HSL: 40 50% 55%) - For borders, highlights, and premium accents
- **Light Gold**: `#EBCC5C` (HSL: 48 100% 50%) - For lighter accents and hover states

### Neutral Colors
- **Background**: Off-white (HSL: 0 0% 98%) - Clean, bright backgrounds
- **Foreground**: Deep Blue-Gray (HSL: 210 30% 20%) - Primary text color
- **Card**: Pure White (HSL: 0 0% 100%) - Card backgrounds for clarity
- **Border**: Light Gray (HSL: 0 0% 90%) - Subtle borders

### Dark Mode
- **Dark Background**: Deep Blue (HSL: 210 80% 12%)
- **Dark Card**: Dark Blue (HSL: 210 70% 18%)
- **Dark Text**: Off-white (HSL: 0 0% 95%)

## Typography

### Fonts
- **Primary**: Poppins (clean, modern, professional)
- **Secondary**: Nunito (friendly, accessible alternative)
- **Fallback**: System fonts for performance

### Font Weights
- **Body**: 400 (regular)
- **Headings**: 600-700 (bold)
- **Buttons**: 600 (semibold)

### Sizing
- **H1**: 2.25rem (36px) - 700 weight
- **H2**: 1.875rem (30px) - 700 weight
- **H3**: 1.5rem (24px) - 600 weight
- **Body**: 1rem (16px) - 400 weight

## Components

### Buttons
- **Primary Button** (`.btn-primary`): Deep Blue gradient
- **Secondary Button** (`.btn-secondary`): Teal gradient
- **Accent Button** (`.btn-accent`): Warm Gold gradient

### Cards
- **Premium Card** (`.card-premium`): White background with soft shadow, rounded corners
- **Hover State**: Elevated shadow with blue border tint

### Effects
- **Glass Effect** (`.glass-effect`): Frosted glass with blue tint
- **Hover Lift** (`.hover-lift`): Smooth elevation on hover with shadow
- **Glow Effects**: Gold and Blue text glow options

### Gradients
- **Background Gradient**: Deep Blue → Teal (smooth, calming)
- **Text Gradients**: Available in Blue, Teal, and Gold

## Shadows

- **Shadow Blue**: Soft blue shadow for depth
- **Shadow Gold**: Warm gold shadow for accents
- **Card Shadow**: Subtle elevation effect

## Spacing & Radius

- **Border Radius**: 0.75rem (12px) - Modern, rounded appearance
- **Padding**: Consistent spacing system
- **Gaps**: Balanced spacing between elements

## Design Principles

1. **Modern & Elegant**: Clean lines, smooth transitions, premium feel
2. **Emotionally Uplifting**: Warm gold accents create positivity
3. **Professional**: Deep blue conveys trust and stability
4. **Accessible**: High contrast ratios for readability
5. **Calming**: Teal and blue create a soothing atmosphere
6. **Welcoming**: Rounded corners and soft shadows feel friendly

## Usage Guidelines

### When to Use Each Color

**Deep Blue**:
- Primary buttons and CTAs
- Main navigation
- Headers and titles
- Important UI elements

**Teal**:
- Secondary actions
- Sidebar accents
- Supporting elements
- Hover states

**Warm Gold**:
- Highlights and accents
- Borders on premium cards
- Icons and decorative elements
- Success states

**White/Light**:
- Card backgrounds
- Content areas
- Clean, readable spaces

## Responsive Design

- Mobile-first approach
- Smooth transitions across breakpoints
- Touch-friendly button sizes (minimum 44px)
- Readable text at all sizes

## Accessibility

- WCAG AA compliant color contrasts
- Clear focus states
- Semantic HTML structure
- Readable font sizes and weights
- Sufficient spacing between interactive elements
