# SMAART Career AI: Detailed Input & Output Specification

This document provides a comprehensive breakdown of every data field required by the system (Input) and every piece of value-add information provided back to the student (Output), as defined in the `aiagent.pdf` Build Guide and the Master Blueprint.

---

## 1. Input Fields: Data Provided by the Student

These fields are collected during the onboarding process and the "Full Profile" completion stage.

### 1.1 Academic Foundation (Onboarding)
- **Domain:** The broad field of study (e.g., Engineering, Management, Arts).
- **Degree Group:** Specific degree category (e.g., B.Tech, B.Com, MBA).
- **Specialization:** The exact major (e.g., Computer Science, Finance, Marketing).

### 1.2 Career Preferences (The "Preference Triple")
The student can select up to **3 Job Preferences** (Primary, Secondary, and Tertiary). For each preference, the system tracks:
- **Sector:** Broad industry (e.g., IT & Software, Banking, EdTech).
- **Job Family:** Functional area (e.g., Data Science, Accounting, Sales).
- **Job Role:** Specific title (e.g., Junior Financial Analyst, Python Developer).
- **Job Type:** Engagement model (Full-time, Internship, Remote, On-site).
- **Expected Salary:** Annual CTC range in LPA (Dropdown selection).
- **Location Preference:** Up to 3 preferred cities.
- **Organization Type:** Preferred workplace environment (Startup, MNC, Govt, NGO).

### 1.3 Professional History
- **Work Experience:**
    - Organization Name
    - Designation
    - Sector & Experience Type
    - Duration (Start & End Dates)
- **Extracurricular Activities:** Participation in clubs, leadership roles, or volunteer work.

### 1.4 Verified Skill & Credentials
- **Skill Name:** The specific technical or soft skill.
- **Certificate Title:** Official name of the certification.
- **Issuing Organization:** (e.g., Google, Coursera, IBM).
- **Year of Completion:**
- **Verification Link:** URL to the digital certificate/badge.

## 2. Output Fields: Value Delivered to the Student

The system processes the inputs above against the **Pre-Built AI Intelligence Table** to generate these outputs.

### 2.1 The Career Matching Engine (Instant Results)
- **Zone Assignment (Color Coding):**
    - 🥇 **Green Zone:** High Match (>50% skill alignment). Indicates high hiring likelihood.
    - 🥈 **Amber Zone:** Moderate Match (25-50% alignment). Requires focused upskilling.
    - 🥉 **Red Zone:** Low Match (<25% alignment). Indicates a major career pivot; requires an "I Understand" acknowledgement.
- **Match Strength:** A percentage score (1-100) showing how well the student's background fits the role.
- **Match Reason:** A one-sentence explanation generated by the AI build phase (e.g., *"Your B.Com Finance foundation is ideal for this risk management role."*).

### 2.2 Combined Learning Path (Instructional Roadmap)
- **Prioritized Skills List:** A list of skills sorted by the **Priority Formula**:
    - **Primary Role Needs:** +10 points
    - **Skill Transfers to Secondary Role:** +5 points
    - **Ready to Learn (Prereq Done):** +8 points
- **Recommended Courses:** Direct links to verified free courses (NPTEL, Google, etc.) mapped to each missing skill.
- **Time Estimates:** Estimated weeks/hours required to reach the Green Zone for the selected role.

### 2.3 Market Intelligence Reports (Career Insights)
- **Technical Skills Matrix:** Must-have vs. Nice-to-have technical competencies.
- **AI Tool Exposure:**
    - **Exposure %:** Percentage of tasks in this role assisted by AI.
    - **Risk/Opportunity Level:** Low, Moderate, or High AI impact.
    - **Mandatory AI Tools:** List of specific tools (e.g., ChatGPT for Excel, Github Copilot).
- **Salary Benchmarking:** Verified entry-level salary ranges for Tier 1 vs. Tier 2 cities in India.

### 2.4 The Skills Passport (Final Deliverable)
- **Narrative Career Summary:** A 3-4 sentence professional pitch generated by Claude 3.5 Sonnet (Cached).
- **Capability Radar Chart:** A visual 7-Quotient chart (CQ, EQ, AQ, XQ, LQ, AIQ, DQ).
- **AI Fluency Evidence:** Specific proof points based on AI-related module completions.
- **Mandatory Disclosure:** A hardcoded legal disclaimer explaining that this is a verified preparation profile.

### 2.5 Engagement Metric (For Placement Officers)
- **Engagement Score:** A weekly calculated score based on Activity Recency, Learning Progress, and Role Stability.
- **Progress Flags:** Indicators showing if a student is "Highly Engaged," "Moderate," or "At-Risk."

## 3. Summary of Data Types

| Field Category | Source | Data Type | Refresh Rate |
|---|---|---|---|
| Academic Stats | Student Input | String/Enum | Once at Signup |
| Job Preferences | Student Input | String/ID | On-Demand Change |
| Matching Results | Pre-Built DB | Number/Enum | Instant (on role change) |
| Learning Path | Formula (Logic) | Dynamic List | Real-time (on skill completion) |
| Passport Narrative | Claude API | Text (JSONB) | Once (Cached) |
| Engagement Score | Batch Job | Number | Weekly (Sunday Night) |
